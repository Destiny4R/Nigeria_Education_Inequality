Data sources, datasets and quality

Every dataset is registered with its origin, licence, limitations and a readiness status assigned by the data-readiness gate. Raw files are never edited.

How data enter this systemBecause the site is open to everyone, there is no web upload. Datasets are imported by the operator from the command line, which records an import job and a versioned checksum.
